# るーちゃんのゆめかわホームページ 🦄🌈

ユニコーン・虹・パステルカラーがいっぱいの、こども向けホームページです。

## ファイル

- `index.html`：ページの内容
- `style.css`：色やレイアウト、スマートフォン対応
- `script.js`：まほうボタン、年の自動更新

`index.html` をブラウザで開くと、手元で確認できます。外部サービスへのデータ送信や情報の収集はありません。

## 保存と公開について

GitHubリポジトリは必ず **Private（非公開）** にしてください。
GitHub Pagesによる公開は行いません。
インターネットに公開する場合は、社内ルールに従い、Next.js・Cloudflare Workers・Cloudflare Accessを使用する構成へ変更してください。
Cloudflare Accessで許可するメールアドレスを制限し、`wrangler.jsonc` の `preview_urls` を `false` にしてください。

プロフィールの文章は作成時のサンプルです。実際の個人情報はリポジトリに保存しないでください。
